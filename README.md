An original one-liner for the make.fun micro bounty **"One Line, One Laugh"** — one line, one laugh, 122 characters.

## The entry

> I told my Wi-Fi router we needed some space — now it won't speak to me, and honestly it's the most stable we've ever been.

## Why it's funny

It opens like a break-up line ("we needed some space") — then the twist: the "partner" is a Wi-Fi router, and the silent treatment, which would be a disaster in a relationship, is exactly what you want from a router. The punchline flips the complaint on its head: a router that never speaks is, by definition, the most stable connection you've ever had. One setup, one turn, one laugh.
